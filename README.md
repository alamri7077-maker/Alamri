# تحليل الاختبار القصير

موقع ثابت (ملف `index.html` واحد) لتحليل مفردات الاختبار، يعمل على GitHub Pages دون خادم.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub (عام Public).
2. ارفع الملفين `index.html` و`README.md` إلى جذر المستودع (Add file ← Upload files).
3. من Settings ← Pages: اختر Source = Deploy from a branch، والفرع `main`، والمجلد `/ (root)`، ثم Save.
4. بعد دقائق يظهر الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

## تشغيل الذكاء الاصطناعي
- افتح الأداة، ثم من «إعدادات الذكاء الاصطناعي» اختر المزوّد وأدخل مفتاح API الخاص بك.
- المزوّدون: Google Gemini (مفتاح من aistudio.google.com)، OpenAI، OpenRouter.
- يُحفظ المفتاح في متصفح المعلم فقط. **لا تضعه داخل الكود أو في المستودع.**
- تُرسل نصوص الاختبار وصورته إلى المزوّد المختار؛ لا ترسل أي بيانات شخصية للطلبة.
